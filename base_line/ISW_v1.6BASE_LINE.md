# Versión v1.6 – Entrega TP6: Desarrollo TDD y Vinculación SCM

La baseline v1.6 se establece tras la finalización e integración documental del Trabajo Práctico Nro. 6, correspondiente a la Unidad Nro. 4: Aseguramiento de Calidad de Proceso y de Producto. 

El objetivo de esta iteración fue aplicar el enfoque de Desarrollo Conducido por Pruebas (TDD) para diseñar y construir software a partir de pruebas automatizadas, poniendo en práctica buenas prácticas de diseño orientado a la calidad. Como grupo impar, el equipo implementó funcionalmente la User Story "Comprar entradas" correspondiente al dominio de EcoHarmony Park. Para ello, se aplicó rigurosamente el ciclo Red-Green-Refactor: escribir una prueba que falle, implementar el código mínimo para que pase y mejorar el diseño del código sin romper las pruebas.

**Estrategia de Trazabilidad y Repositorios Vinculados**
En esta versión, con el aval de la cátedra, se formaliza la estrategia de trazabilidad SCM para los entregables de programación. El repositorio principal actúa exclusivamente como índice normativo, delegando los artefactos técnicos a un repositorio de desarrollo dedicado (`https://github.com/FranciscoDuran78/TP6-ISW-G3-EcoHarmony.git`), donde se mantienen las convenciones nativas del lenguaje.

**Distribución de Ítems de Configuración:**

1. **En el Repositorio Principal (Línea Base actual):**
   * Se integra únicamente el documento proxy `ISW_G3_TP06_resolucion_tdd.pdf` (ubicado en `trabajos_practicos/tp_06/`), el cual cumple con la nomenclatura del Plan SCM y provee el enlace oficial de trazabilidad.

2. **En el Repositorio Secundario (Desarrollo):**
   * Implementación funcional de la User Story.
   * Conjunto de pruebas automatizadas (TDD).
   * Reglas y hoja de estilo de código.

Con este hito, se asegura el acceso auditable a la entrega técnica sin comprometer la estructura de gestión de configuración de este repositorio general.
