# Versión v1.0 – Línea Base Inicial

La baseline v1.0 constituye el punto de partida formal del proyecto. Contiene la estructura inicial de directorios del repositorio y el Plan de Gestión de Configuración de Software (SCM) documentado en el archivo `README.md`. 

A su vez, esta versión integra la carga inicial del material de estudio (presentaciones teóricas y bibliografía) provisto por la cátedra durante las primeras clases. Sirve como base de referencia única para aplicar las prácticas de control de versiones, asegurar la trazabilidad de los cambios y mantener la coherencia estructural durante todo el ciclo de vida de la materia.
