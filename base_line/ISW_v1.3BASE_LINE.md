# Versión v1.3 – Resolución TP2: MVP e Historias de Usuario

La baseline v1.3 se establece tras la finalización e integración del Trabajo Práctico Nro. 2, correspondiente a la Unidad Nro. 2: Gestión Lean-Ágil de Productos de Software. 

El propósito de esta versión es evidenciar la aplicación de conceptos de requerimientos ágiles, abarcando Épicas, Temas, Historias de Usuario (US) y el Producto Mínimo Viable (MVP). El modelado se realizó en base a las necesidades de la aplicación móvil para el dominio "EcoHarmony Park", cubriendo funcionalidades como mapas interactivos, horarios de alimentación, inscripción a actividades y compra de entradas.

Los Ítems de Configuración generados en esta salida y consolidados en el repositorio incluyen:
* La identificación de los roles principales del sistema.
* La definición del MVP, detallando el alcance propuesto y justificando la inclusión y exclusión de las User Stories seleccionadas.
* Las US identificadas con sus respectivas tarjetas completas.
* La redacción de la User Story canónica.
* Las User Stories estimadas.
