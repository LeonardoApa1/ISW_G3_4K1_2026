# Versión v1.2 – Resolución TP1: Historias de Usuario

La baseline v1.2 se establece tras finalizar la resolución del Trabajo Práctico Nro. 1, correspondiente a la Unidad 2: Gestión Lean-Ágil de Productos de Software. 

El objetivo de esta versión es consolidar la aplicación de los conceptos teóricos de requerimientos ágiles. Los Ítems de Configuración generados e integrados al repositorio incluyen la redacción de las Historias de Usuario (US) con sus respectivas pruebas de aceptación. Todo el modelado fue desarrollado en base a las necesidades relevadas para el proyecto de la aplicación "Mis Gastos Familiares".
